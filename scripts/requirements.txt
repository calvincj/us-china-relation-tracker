# Pinned to exact versions, not "at least" (==, not >=) — added 2026-09-04.
# This project already lived through one real "something changed
# underneath us with no warning" incident (Google retired the Gemini
# model this whole pipeline used to run on, see NOTES.md) — an
# unbounded `>=` on any of these has the same failure shape: a
# `pip install` run months from now could silently pull in a major new
# version with breaking API changes, and the first sign of it would be
# a confusing crash, not a clear "your dependency changed" message.
# These are the exact versions this codebase has actually been built
# and tested against.
#
# To intentionally upgrade one: bump the version here, run
# `pip install -r scripts/requirements.txt`, then run the test suite
# (`python code/test_scraper.py` and `python code/test_format_entry.py`)
# and a real `--source <name>` run for anything that library touches
# before trusting it — don't just bump the number and assume it's fine.
